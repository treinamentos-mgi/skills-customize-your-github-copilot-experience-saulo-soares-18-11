
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Desenvolva um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementação do Jogo da Forca

#### Descrição

Implemente o jogo da Forca para que os jogadores tentem adivinhar as letras de uma palavra oculta antes de esgotar as tentativas disponíveis.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e exibir o progresso da palavra no formato `_ _ _`.
- Controlar e atualizar o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou as tentativas incorretas se esgotarem.
- Exibir uma mensagem de vitória ou derrota.
